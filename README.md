# MiniBot 自平衡两轮车系统

一个基于 STM32 的嵌入式自平衡小车，采用 **42步进电机 + LV8731V 驱动器** 实现高精度运动控制，融合传感器融合、PID 控制与姿态解算，实现稳定直立行走。 

## 📌 项目简介

本项目是一个完整的 **两轮自平衡机器人**，从硬件设计到软件开发均由个人独立完成。系统以 **STM32F407** 为主控芯片，通过 **MPU6050（六轴传感器）** 实时采集姿态数据，采用 **互补滤波 + 卡尔曼滤波** 进行姿态解算，并使用 **双环 PID 控制器** 输出控制信号，驱动 **LV8731V 驱动的 42步进电机** 实现精准平衡控制。

与传统直流电机不同，本项目探索了**步进电机在动态平衡系统中的应用**，充分发挥其高扭矩、低速平稳、无累计误差的优势，提升了系统的响应精度与稳定性。

## 📦 功能特性

✅ **自主直立平衡**：上电后自动起立并保持平衡  
✅ **步进电机精准控制**：利用 LV8731V 的 PWM 接口实现平滑调速  
✅ **抗干扰能力强**：在轻微推搡下仍能恢复平衡  
✅ **可调参数**：PID 参数可通过串口动态调整  
✅ **数据监控**：通过串口输出姿态角、目标脉冲频率、控制量等数据

## LV8731V 驱动说明

LV8731V 是一款适用于双极性步进电机的 PWM 恒流驱动器，本项目采用 **Pulse Input 模式**（即外部控制器提供脉冲信号）：

- **控制信号**：
  - `STEP`：来自 STM32 定时器 PWM 输出（决定转速）
  - `DIR`：方向控制 GPIO（决定正反转）
  - `ENABLE`：使能信号（低电平有效）
- **电流设置**：通过外接电阻 `Rs` 设置输出电流（公式：I = Vref / (8×Rs)）
- **优势**：内置续流控制、过热保护、低导通电阻，适合电池供电系统

注：由于步进电机在高速时力矩下降明显。

## PID 控制

- 直立环（角度环）：输出目标角速度（P 控制）
- 速度环（串级）：将角速度转化为左右轮的 PWM 频率差值
- 最终通过 TIMx->CCR1 动态调节 PWM 占空比，控制 LV8731V 输出
